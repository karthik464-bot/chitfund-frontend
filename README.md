# Chit Fund Management System - Frontend

A modern React-based web dashboard for managing chit fund groups, scheme schedules, member enrollments, auctions, and monthly collections.

## 🚀 Tech Stack

- **Frontend:** React.js, HTML5, CSS3 (Glassmorphism UI)
- **Backend API:** Spring Boot (REST APIs)
- **HTTP Client:** Axios

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/karthik464-bot/chitfund-frontend.git
```
